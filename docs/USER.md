# User Documentation

## Introduction
Welcome to the Organization Document Manager. This platform allows you to create, manage, and track documents within your organization, while providing seamless communication tools.

## Key Features

### 1. Document Management
- **Create Documents**: Use pre-defined forms to create documents.
- **Dynamic Forms**: Forms adapt based on the selected version.
- **Attachments**: Upload files associated with your documents.
- **Persian Support**: Full support for Solar (Jalali) dates.

### 2. Automated Reminders
When creating a document with date fields:
- **Set Reminders**: If enabled for the form, you can toggle "Enable Reminder".
- **Notifications**: Receive email alerts on the specified date.
- **Additional Recipients**: Add other email addresses to receive the same reminder.

### 3. Communication (Chat)
Access the **Messages** page from the sidebar:
- **Private Messages**: Search for a colleague and send direct 1-on-1 messages.
- **General Chat**: Participate in organization-wide discussions.
- **Support Chat**: Contact system administrators directly for assistance.
- **Real-time**: Messages refresh automatically.

### 4. Personalization
- **Multilingual UI**: Switch between English and Persian (Farsi) interfaces.
- **Search**: Quickly find users or documents.

## Frequently Asked Questions

### How do I enable a reminder?
When filling out a form, look for the "Reminders" section. If the form administrator has enabled reminders for specific date fields, you will see a toggle to activate them.

### Who can see my private messages?
Only you and the recipient can see private messages. System administrators can only see messages sent to "Support".

### Why can't I see some forms?
Forms must be **Published** and **Active** by an administrator before they are available for document creation.
